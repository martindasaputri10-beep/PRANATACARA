Pangerten Pranatacara

Pranatacara (MC / Master of Ceremony / Pambiwara) yaiku nimpuna utawa wong sing nduweni tugas nglantarake lan ngatur lumakuning sawijining adicara supaya bisa lumaku kanthi rancag, tertib, lan tertata.

Ayahan & Tugas

Tugas utamane yaiku mbuka adicara, maosake runtutan rantaman adicara, ngatur tatanan pembicara/pengisi acara, njaga suasana adicara, lan nuntun adicara nganti pungkasan (panutup).

Syarat Utama

Kudu nguasani basa Jawa kang trep (unggah-ungguh basa), nduweni olah swara kang arum/gandheng, patrap lan busana kang sopan, sarta tanggap marang kahanan adicara (fleksibel).

Petunjuk Penggunaan

1. Registrasi: Isinen Nama, Kelas, lan Presensi ing wiwitan.

2. Alur Level: Lampahi Level 1 nganti Level 6 kanthi urut. Level sabanjure bakal terbuka yen wis ngrampungake level sadurunge.

3. Skor: Saben jawaban bener bakal nambah skor total panjenengan.

4. Final Challenge: Level 6 kasusun saka 30 soal evaluasi lan dibatesi wektu 30 menit.

5. Google Sheets: Ing pungkasan (Halaman Hasil), kirim asil nilai lan refleksi menyang Google Sheets gurumu.

Tujuan Pembelajaran (Fase F)

• Peserta didik mampu menganalisis struktur, isi, lan unggah-ungguh basa ing teks pranatacara.

• Peserta didik mampu menyusun rantaman adicara lan teks pranatacara kanthi runtut lan trep.

• Peserta didik mampu menerapkan teknik olah swara, olah basa, patrap/solah bawa, lan ngadi salira ing simulasi pranatacara.

• Peserta didik mampu mengevaluasi lan mengambil keputusan terpat adhedhasar studi kasus kahanan adicara.

Kode Setup Google Apps Script (Untuk Guru)

1. Buat Google Sheet baru, beri header di Baris 1:

Timestamp | Nama | Kelas | Presensi | Skor | Persentase | Kategori | Refleksi

2. Buka Extensions > Apps Script, hapus kode lama dan tempel kode berikut:

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      data.timestamp,
      data.nama,
      data.kelas,
      data.presensi,
      data.skor,
      data.persentase,
      data.kategori,
      JSON.stringify(data.refleksi)
    ]);
    
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch (error) {
    return ContentService.createTextOutput("Error: " + error.toString()).setMimeType(ContentService.MimeType.TEXT);
  }
}

3. Klik Deploy > New Deployment.

4. Pilih type: Web app.

5. Setel Who has access: Anyone.

6. Salin Web App URL lalu bagikan ke para siswa.
